构建镜像：
docker build -t gameautorunhub:v1.0 .

启动服务（包含MySQL）：
docker compose up -d --build

查看日志：
docker compose logs -f

关闭并移除容器：
docker compose down

打包
docker save -o gameautorunhub_v1.0.tar gameautorunhub:v1.0


加载
docker load -i gamdocker load -i gameautorunhub_v1.0.tar
docker load -i mysql_8.0.tar
