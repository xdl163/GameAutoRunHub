# 挂机管理平台

GameAutoRunHub

------

## 一、总体定位

挂机管理平台用于**多账户、多设备、多任务**的统一管理，支持不同权限角色对设备池与任务进行可控操作，核心目标：

- 设备资源可视、可控、可审计
- 任务全生命周期可追踪
- 积分 / 倍率 / 宝箱等不同任务模型统一管理
- 所有关键操作必须可追溯（审计）

------

## 二、账户与权限体系

### 2.1 角色定义

| 角色       | 层级   | 核心定位                 |
| ---------- | ------ | ------------------------ |
| 超级管理员 | 系统级 | 平台所有能力与系统配置   |
| 管理员     | 业务级 | 管理设备、任务、普通用户 |
| 普通用户   | 操作级 | 仅能操作被授权的任务     |

------

### 2.2 权限矩阵（关键）

> **权限继承规则说明**
>
> - **超级管理员**：拥有 *管理员 + 普通用户* 的全部权限
> - **管理员**：拥有 *普通用户* 的全部权限
> - **普通用户**：仅拥有基础操作权限

------

#### 超级管理员权限（系统级）

> ✅ 拥有 **管理员的所有权限**
>  ✅ 拥有 **普通用户的所有权限**

**额外系统级权限：**

- 账户管理
  - 创建 / 删除 **所有角色**账户
  - 重置 **所有账户**密码
  - 修改用户角色（超级管理员 / 管理员 / 普通用户）
- 系统级配置
  - 平台级配置
  - 全局参数配置

------

#### 管理员权限（业务级）

> ✅ 拥有 **普通用户的所有权限**

**额外管理权限：**

- 普通账户管理
  - 创建 / 删除普通账户
  - 重置普通账户密码
  - 设置普通账户可管理的 **分组**
- 所有人的设备池管理
- 任务管理
  - 可查看、创建、管理、终止 **所有分组的任务**
- 日志查看
  - 查看任务操作日志
  - 查看设备池操作日志
  - 查看账户日志
- 全局参数配置

------

#### 普通用户权限（操作级）

- 任务管理
  - 仅可查看 / 创建 / 管理 / 终止 **被授权分组**下的任务
- 账户
  - 修改自己的密码
- 自己的设备池管理

------

## 五、日志系统（强制审计）

### 5.1 任务操作日志

**记录所有用户对任务的所有操作**

- 创建任务
- 开始 / 暂停 / 补暂停
- 修改任务参数（加单）
- 更换设备
- 终止任务
- 创建分组
- 分组授权
- 取消分组授权

### 5.2 设备池操作日志

记录所有对设备的：

- 新建
- 删除
- 修改状态 / 配置
- 绑定 / 解绑任务

------

### 5.3 账户操作日志

包括但不限于：

- 创建账户
- 删除账户
- 修改角色
- 重置密码
- 修改密码（自己）

------

### 6.1 设备池功能

- 新建设备

- 查看空闲设备
- 根据 **设备ID / 任务ID** 搜索

------

### 6.2 设备状态机

空闲，运行，错误，关机

------

### 6.3 设备表字段设计

| 字段       | 说明                            |
| ---------- | ------------------------------- |
| id         | 自增                            |
| device_id  | 平台内唯一设备ID（字符串）      |
| config     | 设备配置（字符串，可为空）      |
| platform   | 枚举：Android / iOS / 模拟器    |
| remark     | 备注（字符串，可为空）          |
| status     | 枚举：空闲 / 运行 / 关机 / 错误 |
|            | 创建者                          |
| task_id    | 当前绑定任务（可为空）          |
| created_at | 创建时间                        |
| updated_at | 更新时间                        |

## 七、任务管理

任务支持分组

每组下面有三种任务

任务分组管理

有一个默认分组：未分组

支持将某一个任务移动到分组，支持删除分组，组内任务进入未分组

可以设置别的用户管理分组（不支持创建任务）

### 7.1 通用任务操作（所有任务类型通用）

- 开始
- 暂停
- 补暂停（加时 / 加积分）
- 修改（客户加单，不中断）
- 更换设备
- 终止任务（释放设备）

------

### 7.2 任务通用状态机

```text
未开始 → 运行 → 暂停 → 运行 → 完成 → 终止 
                     ↘ 终止
```

------

### 7.3灵光积分

#### 7.3.1 设置页面

- 选择设备（支持模糊搜索）
- 开始时间（默认现在，允许之前或者以后）
- 积分速率（默认 7000 / 小时）
- 目标积分（默认 360000）
- 自动计算展示：
  - 剩余时间
  - 结束时间

------

#### 7.3.2 列表展示字段

| 字段     | 说明     |
| -------- | -------- |
| 设备ID   | 当前设备 |
| 当前积分 | 实时     |
| 剩余时间 | 自动计算 |
| 结束时间 | 自动计算 |

------

#### 7.3.3 操作

- 补暂停：
  - 输入 **积分** 或 **时长**（积分自动换算为时长）
- 暂停 / 开始
- 修改（加目标积分）
- 更换设备
- 终止任务

------

### 7.4挂机倍率

#### 7.4.1 设置页面

- 选择设备（模糊搜索）
- 开始时间（默认现在）
- 时长（小时）
- 快捷按钮：+12h
- 自动计算：
  - 截至时间
  - 结束倍率

> 当前倍率规则：**每秒 +1.15**

------

#### 7.4.2 列表展示字段

| 字段     | 说明     |
| -------- | -------- |
| 设备ID   | 当前设备 |
| 剩余时间 |          |
| 截至时间 |          |
| 当前倍率 | 实时     |

------

#### 7.4.3 操作

- 补暂停（仅时长）
- 暂停 / 开始
- 修改（加时）
- 更换设备
- 终止任务
